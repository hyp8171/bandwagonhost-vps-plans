## 购买前要留意的几件事

### “最高带宽”不等于实际速度保证

官网常规套餐页标注 1 Gbps 链路速度，品牌介绍页则概括所有 VPS 包含 1–10 Gigabit uplink。不同方案或节点可能有差异，页面上的链路上限不能直接等同于单个用户持续可达到的下载速度。实际表现还与网络路径、节点拥塞和目标服务有关。

### 自管理意味着需要自己处理系统

官网说明服务运行在 KVM 虚拟化平台，KiwiVM 面板提供基本管理功能；同时，服务被定位为 self-managed。换句话说，面板可以帮你管理 VPS 实例，但不能据此认为主机商会替你安装、维护所有应用或处理网站层面的配置。

### 不要把旧优惠当成当前促销

检索到的历史文章会列出 THE PLAN 2024 的标价、机房数和补货信息，但官网当前公开首页列出的是六种常规 KVM 套餐，未列出该限量款。也没有在当前官方公开页面中核实到 THE PLAN 2024 仍有效的优惠码或补货时间。因此，不应把旧价格写成“现在只要 $99”，也不应把历史补货消息当作购买保证。
